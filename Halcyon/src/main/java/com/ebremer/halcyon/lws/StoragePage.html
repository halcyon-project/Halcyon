Add a storage by URI
A local or remote W3C Linked Web Storage — connecting to storage on another server is a central point of LWS. Paste its root URI (or its .description); it is validated by fetching its storage description. A remote storage is browsed anonymously — your access token is never sent to another server. Added storages are remembered in this browser.
